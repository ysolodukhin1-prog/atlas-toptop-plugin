# GALACTICA TOPTOP — подключение к Codex по ссылке

Плагин добавляет в Codex и Claude Code доступ к GALACTICA TOPTOP и четыре навыка работы с контекстом, памятью задач, итогами и отчётами.

## Установить в Codex

Скопируй в свой Codex одно сообщение:

> Установи плагин GALACTICA TOPTOP по ссылке https://github.com/ysolodukhin1-prog/galactica-toptop-plugin. Прочитай SETUP_FOR_CODEX.md, установи плагин и подключи его через TREND во встроенном браузере Codex. Открой GALACTICA и TREND в двух вкладках и отдельно проверь подключение MCP.

Файлы пересылать не нужно. Codex прочитает инструкцию прямо из репозитория. Само открытие ссылки в браузере ничего не устанавливает: отправь ссылку Codex вместе с просьбой установить плагин.

После установки начни новый чат. Напиши: **«Подключи меня к GALACTICA TOPTOP, проверь мою учётную запись и покажи доступные знания, отчёты и базы».**

Вход выполняется **во встроенном браузере Codex на обычной странице TREND**. Используй свой личный логин; при действующей сессии повторный ввод пароля обычно не нужен. Codex завершит подключение, проверит учётную запись и откроет GALACTICA и TREND в двух вкладках. Пароль в чат не отправляй. Для этого сценария нужен Codex desktop с управлением встроенным браузером и поддержкой `--no-browser`; помощник проверит совместимость перед входом.

Нужны установленный Codex и выданные администратором персональные права TOPTOP. Python, ZIP, SSH и локальная база не требуются. Установка сама по себе не выдаёт доступ к данным.

## Обновление уже установленного плагина

Отправь своему Codex:

> Обнови GALACTICA TOPTOP по https://github.com/ysolodukhin1-prog/galactica-toptop-plugin/blob/main/SETUP_FOR_CODEX.md. Обнови каталог и установленный пакет. Используй встроенный браузер Codex для входа, открой GALACTICA и TREND в двух вкладках. Если MCP вернёт ошибку, всё равно открой интерфейсы и сообщи ошибку отдельно.

После обновления начни новый чат, чтобы загрузились обновлённые навыки. Повторный вход нужен только при недействующем подключении. В новой сборке инструкция браузерного входа входит в сам навык `toptop-workflow`; в каталоге отключён вход непосредственно при установке (`ON_USE`). Сам плагин не может принудительно выбрать браузер: для этого Codex должен выполнить поставляемый сценарий и иметь инструменты управления встроенным браузером.

## Что доступно

- Проектный контекст и поиск знаний.
- Задачи, память работы, сохранение и повторное чтение итогов.
- Изменение разрешённых Markdown с проверкой текущего SHA.
- Каталог персонально разрешённых отчётов и источников TREND.
- Чтение разрешённых отчётов и ограниченные запросы к доступным базам, включая Розницу, УТ и ERP 1С; разрешённые методы MPStats.

Помощник сначала узнаёт каталог и структуру источников. Произвольный SQL и изменение исходных данных не предоставляются. Права TREND на отчёты и базы и персональные ограничения GALACTICA на знания проверяются сервером. Разрешение на знания не расширяет доступ к данным TREND.

## Состояние на 28 сентября 2026

Установка проверена в чистых профилях Codex и Claude Code. Рабочий сценарий с личным входом, знаниями, данными и сохранением итога проверялся в настоящем Codex. Полная проверка всех сценариев ещё не завершена: медиаплан может превышать время ожидания, соединение с 1С нестабильно; полный сценарий Claude Code и автоматический refresh настоящим клиентом требуют завершения проверки. Импортированные методики сохраняют происхождение и статус проверки.

Сервер использует срок **3 часа бездействия**. Реальные действия продлевают сессию; фоновые проверки — нет. Для старых подключений, выданных до добавления refresh, нужен один повторный вход.

## Состав

- `plugins/galactica-toptop/` — MCP и четыре навыка;
- `.agents/plugins/marketplace.json` — каталог Codex;
- `.claude-plugin/marketplace.json` — каталог Claude Code.

В репозитории находятся только настройки, навыки и инструкции. Секреты и рабочие данные в репозиторий не включаются.
