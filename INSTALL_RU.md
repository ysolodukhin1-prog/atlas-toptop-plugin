# Как подключиться к GALACTICA TOPTOP

Нужны установленный Codex или Claude Code и личная учётная запись TREND с разрешённым доступом к GALACTICA TOPTOP. Python, ZIP, SSH и база на компьютере не нужны.

## В Codex

1. Скопируй в чат Codex это сообщение:

   > Установи плагин GALACTICA TOPTOP из https://github.com/ysolodukhin1-prog/galactica-toptop-plugin. Прочитай SETUP_FOR_CODEX.md и выполни установку. Затем проверь мой вход, права и контекст TOPTOP.

2. Подтверди установку **GALACTICA TOPTOP**, если Codex попросит.
3. Начни новый чат. Напиши: **«Подключи меня к GALACTICA TOPTOP»**.
4. На странице входа введи свой логин и пароль **TREND**. Если ты уже вошёл в TREND в этом браузере, повторный ввод не нужен. Нажми **«Подключить»**. Пароль не нужно отправлять в чат.
5. Попроси: **«Проверь whoami, загрузи контекст TOPTOP и начни задачу»**.

Если вход не появился, попроси Codex выполнить `codex mcp login galactica_toptop_client`. При запросе разреши создавать задачи и сохранять итоги. Изменения общих Markdown дополнительно требуют прав менеджера или владельца.

## В Claude Code

1. Введи `/plugin marketplace add ysolodukhin1-prog/galactica-toptop-plugin`.
2. Введи `/plugin install galactica-toptop@toptop-galactica`.
3. Начни новую сессию.
4. Открой `/mcp`, выбери подключение GALACTICA TOPTOP и нажми вход. Войди личным логином и паролем **TREND**, затем нажми **«Подключить»**.
5. Напиши: **«Проверь whoami и загрузи мой контекст TOPTOP из GALACTICA»**.

## Текущие показатели из TREND

Для TREND, сайта GALACTICA, Codex и Claude Code используется **одна личная учётная запись TREND**. Отдельный аккаунт GALACTICA и отдельное подключение TREND не нужны.

Попроси помощника прочитать текущий ABC-отчёт через `trend_read_abc`. Пароль не сохраняется в MCP. Сессия источника хранится зашифрованной на сервере и проверяется при каждом вызове. Сейчас доступны ABC-сводка и таблица Ozon/Wildberries; остальные отчёты и произвольный SQL пока не доступны.

## Что должен сделать администратор

В управлении пользователями TREND открой личного пользователя руководителя или создай его там один раз. Выдай:

- доступ к аккаунту TOPTOP;
- в доступах к данным **GALACTICA TOPTOP → Контекст и знания**;
- **Задачи и итоги**, чтобы помощник мог сохранять результаты;
- **Изменение Markdown**, только если нужны изменения общих документов;
- для текущих показателей — отчёт ABC и его данные в источнике **Маркетплейсы · TOPTOP**.

Сохрани пользователя. После изменения прав ему может потребоваться повторный вход. Отключение пользователя или отзыв личной сессии TREND закрывает и доступ из помощника. Свою администраторскую учётную запись передавать не нужно.

## Как проверить, что всё работает

Отправь помощнику:

> Проверь мою личность и права. Загрузи контекст TOPTOP. Начни тестовую задачу, прочитай разрешённые данные TREND, запиши короткий итог и повторно прочитай его через read_task. Назови реальные результаты проверок.

Если доступ запрещён, администратор должен проверить разрешения пользователя в TREND. Установка плагина сама по себе не выдаёт права. При отзыве доступа TREND чтение прекращается.
