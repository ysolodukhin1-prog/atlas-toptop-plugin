# GALACTICA TOPTOP: репозиторий клиентского плагина

Этот каталог подготовлен как отдельный GitHub-репозиторий. Его плагин подключает Codex и Claude Code к удалённому MCP GALACTICA и устанавливает навыки работы с контекстом, памятью задач, итогами и отчётами. Пользователю не нужны Python, ZIP, SSH-ключи или локальная копия базы.

Понятная инструкция для клиента: [INSTALL_RU.md](INSTALL_RU.md). Инструкция, которую Codex прочитает по GitHub-ссылке: [SETUP_FOR_CODEX.md](SETUP_FOR_CODEX.md). Серверные требования: [SERVER_CONTRACT.md](SERVER_CONTRACT.md).

## Состояние

Код плагина и два каталога marketplace опубликованы в [ysolodukhin1-prog/galactica-toptop-plugin](https://github.com/ysolodukhin1-prog/galactica-toptop-plugin). Это версия для подготовки и проверки. Публичный MCP `https://83.222.17.242/galactica-mcp/mcp` пока не развёрнут, поэтому подключение клиентов к данным ещё не готово. OAuth, права, TREND и полный цикл в Codex/Claude требуют сквозной проверки.

После публикации администратор создаст одну ссылку `codex://new?prompt=...` командой `python make_onboarding_link.py https://github.com/OWNER/REPO` **на своём компьютере**. Она откроет Codex с готовым запросом подключить плагин из репозитория. Пользователь отправит запрос, подтвердит установку и лично войдёт в GALACTICA. Codex может выполнить команды `codex plugin marketplace add OWNER/REPO` и `codex plugin add galactica-toptop@toptop-galactica` на компьютере клиента; эти команды проверены по текущему CLI. Сама ссылка не запускает установку без действия пользователя.

## Что будет в GitHub

- `plugins/galactica-toptop/` — один плагин с MCP и четырьмя навыками;
- `.agents/plugins/marketplace.json` — каталог для Codex;
- `.claude-plugin/marketplace.json` — каталог для Claude Code;
- эти инструкции и серверный контракт.

Репозиторий хранит только код настройки и навыки. Пользовательские данные, сессии и токены остаются на стороне GALACTICA. Обновления инструкций распространяются через версии плагина в GitHub; права проверяются сервером при каждом запросе.

## Перед публикацией

1. Развернуть MCP и общий HTTPS-вход GALACTICA; проверить роль TOPTOP и доступ к TREND.
2. Проверить оба каталога и реальную установку плагина из GitHub на тестовом аккаунте.
3. Проверить вход, `whoami`, контекст, навыки, задачу, итог и отзыв доступа.
4. Только после этого сообщить клиентам настоящий `OWNER/REPO` и открыть установку.

Существующий `galactica_toptop_direct` использует личный SSH-ключ ноутбука и клиентам не передаётся.
