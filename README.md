# GALACTICA TOPTOP: репозиторий клиентского плагина

Этот каталог подготовлен как отдельный GitHub-репозиторий. Его плагин подключает Codex и Claude Code к удалённому MCP GALACTICA и устанавливает навыки работы с контекстом, памятью задач, итогами и отчётами. Пользователю не нужны Python, ZIP, SSH-ключи или локальная копия базы.

Понятная инструкция для клиента: [INSTALL_RU.md](INSTALL_RU.md). Инструкция, которую Codex прочитает по GitHub-ссылке: [SETUP_FOR_CODEX.md](SETUP_FOR_CODEX.md). Серверные требования: [SERVER_CONTRACT.md](SERVER_CONTRACT.md).

## Состояние

Плагин опубликован в [ysolodukhin1-prog/galactica-toptop-plugin](https://github.com/ysolodukhin1-prog/galactica-toptop-plugin). HTTPS MCP `https://83.222.17.242/galactica-mcp/mcp` развёрнут и проходит проверку сертификата. Проверены реальная установка в чистых профилях Codex и Claude Code и серверный сценарий с отдельным пользователем: OAuth/PKCE, личность, контекст, текущие данные TREND, запись и повторное чтение итога, запреты чужих данных и отзыв прав.

TREND, сайт GALACTICA и оба помощника используют одну личную учётную запись TREND. Отдельная регистрация GALACTICA и привязка TREND не нужны. Права на контекст, задачи, Markdown и данные задаются в TREND. MCP проверяет исходную личную сессию и текущие права при каждом вызове. Пароль не сохраняется, сессия источника зашифрована. Пока доступны ABC-сводки и таблицы Ozon/Wildberries; остальные отчёты и произвольный SQL пока не включены. 37 импортированных методов сохраняют происхождение и статус «не проверен в TOPTOP».

Отправь руководителю [инструкцию установки](https://github.com/ysolodukhin1-prog/galactica-toptop-plugin/blob/main/INSTALL_RU.md). В ней есть готовое сообщение для его Codex и две команды для Claude Code. Пользователь подтверждает установку и входит под своей учётной записью. Установка не выдаёт дополнительных прав.

## Состав плагина

- `plugins/galactica-toptop/` — один плагин с MCP и четырьмя навыками;
- `.agents/plugins/marketplace.json` — каталог для Codex;
- `.claude-plugin/marketplace.json` — каталог для Claude Code;
- эти инструкции и серверный контракт.

Репозиторий хранит только код настройки и навыки. Пользовательские данные, сессии и токены остаются на стороне GALACTICA. Обновления инструкций распространяются через версии плагина в GitHub; права проверяются сервером при каждом запросе.

## Проверка настоящим клиентом

28 сентября 2026 плагин 0.3.0 и отдельный пользователь TREND без пароля GALACTICA прошли полный сценарий в настоящем Codex на ноутбуке: общий вход, личность и права, контекст, знания, четыре навыка, текущая сводка и строки TREND, журналируемая запись Markdown, отказ при старом SHA, сохранение итога и точное повторное чтение. Задача: `7660fe2b-9d16-4c51-8d93-266297eb6387`. Также проверены повторное использование сессии TREND, отзыв прав и сессии, отключение пользователя, запрет чужих данных и отсутствие восстановления старого токена после нового входа. Установка 0.3.0 в чистые профили Codex и Claude Code проверена; полный сценарий выполнения задачи в Claude Code отдельно не проверен.

Время обновления данных источника пока не подтверждено. Импортированные методы не объявляются проверенными в TOPTOP. Сохранение итога проверено; последующая обработка очереди протоколайзером в этот тест не входит.

Существующий `galactica_toptop_direct` использует личный SSH-ключ ноутбука и клиентам не передаётся.
