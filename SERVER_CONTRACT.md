# Серверный контракт для дочерней GALACTICA TOPTOP

## Граница доверия

Клиент устанавливает плагин из GitHub marketplace GALACTICA. Плагин содержит URL `https://83.222.17.242/galactica-mcp/mcp` и навыки; живые данные и права остаются на сервере. Сервер реализует MCP Streamable HTTP и OAuth 2.1 Authorization Code + PKCE поверх личного входа TREND. Пользователь имеет явные права GALACTICA TOPTOP в TREND; действующая сессия и права TOPTOP проверяются при выдаче токена **и на каждом вызове**. Токен имеет audience дочернего MCP, короткий срок жизни и отдельные scopes `toptop:read`, `toptop:task`, опционально `toptop:write`. Отзыв пользователя, сессии или членства прекращает доступ без ожидания истечения токена.

Публичный endpoint публикует OAuth Protected Resource Metadata и Authorization Server Metadata. `401` содержит `WWW-Authenticate` с `resource_metadata`. Код согласия одноразовый, связан с `client_id`, `redirect_uri`, `resource` и PKCE challenge; динамическая регистрация клиентов или CIMD поддерживается явно. Токены, коды и verifier никогда не попадают в Markdown, журналы задач или ответы MCP.

Сервер связывает каждую операцию с подтверждёнными `user_id`, `project_id`, `client_id`, `scopes`. Значения `agent_id`, `project_id` и роль из аргументов инструмента не считаются авторизацией. Оба помощника используют общий вход TREND/GALACTICA TOPTOP. Уже открытая личная сессия TREND используется без второго пароля. Внутренний GALACTICA principal создаётся как проекция подтверждённого ID TREND, без local_login. Каждое OAuth-подключение связано со своей исходной зашифрованной сессией; новый вход не оживляет отозванный токен. Права `context`, `tasks`, `markdown` выдаются в источнике `galactica:toptop` управления пользователями TREND. Доступ к отчётам дополнительно требует TOPTOP, ABC и `marketplace:toptop/abc`. Общий администраторский cookie не заменяет личный вход. Локальная блокировка GALACTICA также учитывается. Права источника проверяются до и после чтения. PostgreSQL `galactica_autonomy` — канон знаний; Qdrant и Neo4j — индексы. Токен MCP действует до часа; автоматический refresh пока не реализован, требуется повторный вход.

## Инструменты первой версии

| Инструмент | Право | Контракт |
| --- | --- | --- |
| `whoami` | read | Личный ID, TOPTOP, scopes, срок сессии; без токена |
| `get_context` | read | Наследуемые Markdown для указанного пути, версии и SHA каждого документа; ограничение размера |
| `search_knowledge` | read | Поиск в пределах TOPTOP; ID, вид, эпистемический статус, источник, версия, фрагмент |
| `get_knowledge` | read | Каноническая строка PostgreSQL по ID; при отсутствии доступа 404 |
| `list_skills` / `get_skill` | read | Только активные дочерние процедуры и отдельно помеченные кандидаты; источник, версия, статус проверки |
| `start_task` | task | Идемпотентный UUID, запрос, критерии, точный источник, actor из токена |
| `record_message` | task | Только точный доступный текст с источником; частичное/отредактированное помечать |
| `finish_task` | task | Структурированный аутком по существующей схеме; неизменяемый итог и очередь протоколайзера |
| `read_task` | read | Только собственная задача и сохранённый итог |
| `trend_read_abc` | read | Только разрешённые текущие ABC summary/stats Ozon/Wildberries; остальные отчёты и SQL не подключены |
| `read_document` | read | Текущий Markdown, logical key, версия, SHA |
| `write_document` | markdown | Журналируемая запись с expected SHA и task ID; 409 при конфликте; отдельное право |

`reconcile`, `import_canonical`, `accept_import`, администрирование навыков и доступ к чужим проектам не входят в клиентский набор. Материнские методы отчётов — справочные кандидаты с происхождением, а не активные инструкции без проверки. Если пользователь запросит правку Markdown, её право выдаётся отдельно. Никаких прямых SQL, произвольных путей, SSH и универсального `run_command` у клиента нет.

## Результаты внедрения

Развёрнуты HTTPS MCP, OAuth PKCE и DCR, проверка личности и членства при каждом вызове, адаптер канонических знаний и задач, журналируемый Markdown и личный доступ TREND. Отдельный пользователь прошёл полный сценарий в настоящем Codex: установка, вход, контекст, знания и навыки, текущие данные, задача, запись, итог и повторное чтение. Проверены запреты без входа, чужой задачи/клиента, старого SHA и отзыв прав. Установка Claude Code проверена; полный сценарий выполнения задачи в Claude Code отдельно не проверен. Сохранение итога подтверждено, завершение дальнейшей обработки протоколайзером не проверено. Время обновления данных источника пока не подтверждено.

**Права в TREND:** context → reader; context + tasks → contributor; context + tasks + markdown → manager. Отдельный local_login не создаётся. Отключение личного пользователя, отзыв сессии или разрешений TREND прекращает доступ MCP. Локальная блокировка GALACTICA дополнительно запрещает доступ. Установка не выдаёт права. Codex CLI запускается только на ноутбуке. PULSE КОКОС не является источником TOPTOP.
