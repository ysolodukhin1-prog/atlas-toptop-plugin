# Подключение TOPTOP GALACTICA к Codex и Claude

Клиенту не нужен Python или ZIP. Администратор даст одну ссылку для Codex. Она откроет новый чат с готовым запросом установить плагин GALACTICA из GitHub. Плагин добавляет MCP и навыки; данные TOPTOP остаются на сервере.

**Пока это проект инструкции:** [плагин опубликован в GitHub](https://github.com/ysolodukhin1-prog/galactica-toptop-plugin), но публичный MCP ещё не запущен. Подключение к данным станет доступно после проверки MCP и входа GALACTICA.

## Если работаешь в Codex

1. Нажми ссылку, которую прислал администратор. Откроется Codex с готовым запросом.
2. Отправь запрос. Codex проверит GitHub-репозиторий, добавит marketplace и установит плагин. Если он попросит подтвердить установку, подтверди после проверки названия **GALACTICA TOPTOP**.
3. Начни новый чат, чтобы загрузились навыки. При запросе войди в свою учётную запись GALACTICA. Codex проверит `whoami` и контекст TOPTOP.

## Если работаешь в Claude Code

1. В Claude Code выполни `/plugin marketplace add ysolodukhin1-prog/galactica-toptop-plugin`.
2. Выполни `/plugin install galactica-toptop@toptop-galactica`.
3. Начни новую сессию и попроси: «Загрузи мой контекст TOPTOP из GALACTICA». При запросе войди в свою учётную запись GALACTICA.

Если используешь только одного помощника, достаточно выполнить только его раздел. Администратор GALACTICA отдельно выдаёт тебе право на TOPTOP. Пароль вводи только на странице входа GALACTICA; не пересылай пароль или токен.

После подключения попроси помощника вызвать `whoami` и `get_context`. Если вход прошёл, но доступ запрещён, попроси администратора проверить членство в TOPTOP. Для текущих показателей TOPTOP помощник должен пользоваться разрешённым доступом к TREND.
