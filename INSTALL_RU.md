# Как подключиться к GALACTICA TOPTOP

Нужны установленный Codex или Claude Code и личная учётная запись GALACTICA с доступом к TOPTOP. Python, ZIP, SSH и база на компьютере не нужны.

## В Codex

1. Скопируй в чат Codex это сообщение:

   > Установи плагин GALACTICA TOPTOP из https://github.com/ysolodukhin1-prog/galactica-toptop-plugin. Прочитай SETUP_FOR_CODEX.md и выполни установку. Затем проверь мой вход, права и контекст TOPTOP.

2. Подтверди установку **GALACTICA TOPTOP**, если Codex попросит.
3. Начни новый чат. Напиши: **«Подключи меня к GALACTICA TOPTOP»**.
4. На странице входа GALACTICA введи свой логин и пароль. Нажми **«Подключить»**. Пароль не нужно отправлять в чат.
5. Попроси: **«Проверь whoami, загрузи контекст TOPTOP и начни задачу»**.

Если вход не появился, попроси Codex выполнить `codex mcp login galactica_toptop_client`. При запросе разреши создавать задачи и сохранять итоги. Изменения общих Markdown дополнительно требуют прав менеджера или владельца.

## В Claude Code

1. Введи `/plugin marketplace add ysolodukhin1-prog/galactica-toptop-plugin`.
2. Введи `/plugin install galactica-toptop@toptop-galactica`.
3. Начни новую сессию.
4. Открой `/mcp`, выбери подключение GALACTICA TOPTOP и нажми вход. На странице GALACTICA введи личный логин и пароль, затем нажми **«Подключить»**.
5. Напиши: **«Проверь whoami и загрузи мой контекст TOPTOP из GALACTICA»**.

## Текущие показатели из TREND

Авторизация GALACTICA одинакова для обоих помощников. Для данных TREND нужна привязка твоей личной учётной записи TREND:

1. После входа GALACTICA открой [подключение TREND](https://83.222.17.242/galactica-mcp/trend/connect).
2. Введи личный логин и пароль TREND. Нужны права на TOPTOP, отчёт ABC и его данные.
3. Нажми **«Подключить TREND»**. Привязка будет доступна и Codex, и Claude Code.
4. Попроси помощника прочитать текущий ABC-отчёт через `trend_read_abc`.

Пароль TREND не сохраняется. Сессия источника хранится зашифрованной на сервере. Когда она истечёт, повтори вход. Пока MCP предоставляет текущие данные ABC для Ozon и Wildberries: сводку и таблицу. Остальные отчёты и произвольный SQL через плагин пока не доступны.

## Как проверить, что всё работает

Отправь помощнику:

> Проверь мою личность и права. Загрузи контекст TOPTOP. Начни тестовую задачу, прочитай разрешённые данные TREND, запиши короткий итог и повторно прочитай его через read_task. Назови реальные результаты проверок.

Если доступ запрещён, администратор должен проверить членство в TOPTOP и личные права на данные TREND. Установка плагина сама по себе не выдаёт права. При отзыве членства GALACTICA или прав TREND чтение прекращается.
